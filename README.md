# Obsidian AI Assistant — Учебный проект

> Для студентов: Этот плагин намеренно сделан "неидеальным". Твоя задача — понять, как он работает, и предложить улучшения.

Плагин для Obsidian, позволяющий работать с AI-моделями через Hugging Face API прямо в редакторе: исправлять текст, делать конспекты, объяснять сложные темы и вести диалог.

---

## Быстрый старт

### Требования

| Что нужно | Зачем | Где взять |
|-----------|-------|-----------|
| Obsidian (Desktop) | Среда для работы плагина | [obsidian.md](https://obsidian.md) |
| Node.js 18+ | Для сборки проекта | [nodejs.org](https://nodejs.org/) |
| Git | Для клонирования и отправки решений | [git-scm.com](https://git-scm.com) |
| API-ключ Hugging Face | Доступ к AI-моделям | [Получить бесплатно](https://huggingface.co/settings/tokens) |

### Установка

```bash
# Клонируй репозиторий
git clone https://github.com/ripidipi/Obsidian-plugin.git
cd Obsidian-plugin

# Установи зависимости
npm install

# Собери плагин (режим разработки с авто-пересборкой)
npm run dev
```

### Подключение к Obsidian

1. Найди папку своего хранилища (в Obsidian: Настройки → Общее → Папка хранилища → Показать)
2. Перейди в `.obsidian/plugins/` внутри хранилища
3. Создай папку `ai-assist` и скопируй туда:
   - main.js (создаётся после сборки)
   - manifest.json (файл описания плагина)
   - prompts.json (конфиг с промптами)
   А лучше и удобнее для модернизации скопировать туда сразу весь клонированный проект
4. В Obsidian: Настройки → Сторонние плагины → отключи "Безопасный режим" → найди AI Assist → включи

### Настройка

1. Открой Настройки → AI Assistant
2. Вставь API Key (начинается с `hf_...`)
3. Выбери модель (рекомендуем: `meta-llama/Llama-3.3-70B-Instruct:groq`)

### Проверка работы

- Открой палитру команд (Ctrl+P / Cmd+P) → введи `AI:`
- Выбери `AI: Open Chat` → откроется панель чата
- Выдели текст в заметке → вызови `AI: Quick Menu` → нажми кнопку

## Частые вопросы

**Почему модель отвечает кратко или невпопад?**
Скорее всего, инструкция в `prompts.json` слишком общая. Попробуй добавить конкретики: что делать, в каком формате, что учитывать.

**Я поправил `prompts.json`, но ничего не изменилось**
Проверь: файл сохранён, плагин пересобран (`npm run build`), плагин перезапущен в Obsidian, в JSON нет синтаксических ошибок.

**Как отладить, если что-то не работает?**
Открой консоль разработчика в Obsidian (Ctrl+Shift+I / Cmd+Option+I), перейди во вкладку Console, воспроизведи проблему и скопируй текст ошибки.
